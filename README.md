# Sistema de Gestão de Notas 

Sistema desenvolvido em Python para praticar lógica de programação e os fundamentos do desenvolvimento de software.

## Funcionalidades

- Cadastro de alunos e notas.
- Cálculo automático da média.
- Verificação da situação do aluno (aprovado ou reprovado).
- Listagem de alunos cadastrados e suas médias.
- Busca de alunos pelo nome.
- Validação de notas entre 0 e 10.

## Tecnologias utilizadas

- Python 3
- Dicionários para armazenar dados.
- Funções e estruturas de controle.
- Tratamento de erros de entrada.

## Como executar

1. Instale o Python 3 no computador.
2. Baixe o arquivo `main.py`.
3. Abra o terminal na pasta do arquivo.
4. Execute o comando:

```bash
python main.py
```
